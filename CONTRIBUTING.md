# Contribuir a Hubly

Gracias por tu interés. Hubly está empezando, así que tu experiencia real cuenta tanto como el código.

## Formas de ayudar

- **Cuéntanos cómo trabaja tu agencia:** qué herramientas usas y qué te quita más tiempo.
- **Propón ideas:** abre un issue con el problema que quieres resolver.
- **Reporta errores de la landing:** indica el navegador y los pasos para reproducirlos.
- **Envía código:** para cambios grandes, abre primero un issue y lo conversamos.

## Trabajar en la landing

```bash
cd web
npm install
npm run dev
```

Antes de abrir un pull request, comprueba que `npm run build` termina sin errores.
