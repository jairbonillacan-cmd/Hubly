# ADR 0002: SaaS alojado y licencia

Estado: SaaS aceptado, 1 de noviembre de 2026. **Licencia a largo plazo: pendiente.**

## Decisión
Hubly se ofrece como SaaS que opera su propio equipo, sin soportar instalaciones de terceros como producto.

## Situación actual
El repositorio es público y el archivo `LICENSE` y la landing declaran AGPL-3.0. El SaaS es compatible con eso. Lo que no cambia solo es la promesa pública de «código abierto», que se mantiene hasta decidir.

## Pendiente
- Mantener AGPL y público, o cerrar el código.
- No se incorpora código de Postiz (ADR 0003), para no limitar esta decisión.
- Cerrar el código solo afecta versiones futuras: lo ya publicado sigue disponible bajo AGPL para quien lo tenga.
- Cambiar la licencia del código ya publicado requiere revisión legal.
